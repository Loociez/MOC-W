Playable Classes

Mirage Online Classic currently has 11 playable classes. Each has its own base Health / Mana / Stamina, combat stats, and its own rate of growth per level. Base values below apply at level 1; growth values show how much a stat gains each level, and how that growth changes once a class reaches its listed level interval.

Reading the Growth Columns

Per-Level Growth is how much a stat increases each level, starting from the Base value at level 1. Growth Change After Interval is a modifier applied to that per-level growth once the class passes its Interval Level (for example, most classes see their HP/MP/SP growth drop once they pass level 50). Regen Change After Interval works the same way but affects passive HP/MP/SP regeneration rather than the stat gained on level-up. These are taken directly from the game's class data — exact in-game behavior should be verified in testing before treating this as authoritative for build planning.
