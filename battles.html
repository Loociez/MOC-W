Battle Activities

Mirage Online Classic currently has 11 active battle activities. Each activity is a walkable path made up of a set of linked maps (by Map ID). While travelling on any map linked to an activity, a battle check occurs every listed number of steps, with a percentage chance of triggering an encounter on that check. "Group" activities are intended to be taken on with a party, while "Solo" activities can be done alone.

Reading the Battle Data

Steps per Check is how many steps you need to take on a linked map before a battle check happens. Battle Chance is the percentage chance, on that check, that a battle actually triggers. Map IDs are the game's internal identifiers for each map — all maps listed under an activity share the same step and chance values. These are taken directly from the game's activity data; exact in-game behavior should be verified in testing before treating this as authoritative.
