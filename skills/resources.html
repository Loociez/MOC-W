Gathering Nodes

Mirage Online Classic currently has 12 active gathering resource types across Fishing, Prospecting (Mining), and Lumberjacking (Woodcutting). Each node spawns a set number of gatherable instances on its map, which replenish after a fixed delay once depleted. Gathering from a node has a chance to award a guaranteed "drop" item and a separate chance to award a bonus "gather" item on top of it.

Reading the Resource Data

Spawn Amount is how many gatherable instances exist on a node's map at once. Respawn/Replenish Delay is how long, in seconds, a depleted instance takes to become gatherable again. Drop Item rows are the primary items you can receive for a successful gather, each with its own chance and amount. Bonus Gather Item rows are secondary items that can additionally be awarded on top of a drop. These are taken directly from the game's resource data; exact in-game behavior should be verified in testing before treating this as authoritative.
